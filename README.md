# Quiet Reader

Минималистичная PDF-читалка в стиле Kindle.

## Запуск
1. Распакуй архив в отдельную папку.
2. Открой терминал в этой папке.
3. Запусти локальный сервер:

   **Windows (PowerShell):**
   ```powershell
   py -m http.server 8000
   ```

   **Linux:**
   ```bash
   python3 -m http.server 8000
   ```

4. Открой в браузере `http://localhost:8000`.
5. Нажми «Открыть книгу» и выбери свой PDF.

Нужен интернет при первом запуске для загрузки PDF.js с CDN. Сам PDF остаётся на устройстве: приложение читает его локально в браузере.

## Уже работает
- открытие PDF;
- постраничный просмотр и масштабирование;
- текстовый слой для выделения текста;
- переход по страницам и клавиатурные стрелки;
- темы «Бумага», «Сепия», «Ночь»;
- сохранение прогресса в localStorage;
- закладки;
- личный словарь;
- перевод выделенного текста через Google Translate.

## Ограничения первой версии
- Прогресс и словарь хранятся в браузере на этом устройстве.
- Перевод открывается во внешней вкладке.
- PDF.js и шрифты загружаются из интернета.
